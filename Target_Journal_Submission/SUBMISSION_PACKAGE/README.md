# Submission Package — JCIM

**Applicability-Domain Conditional Conformal Prediction: Distribution-Free Coverage over
Chemical-Space Shifts without Density-Ratio Estimation**

| Folder | Contents |
|---|---|
| 01_Cover_Letter | Cover letter (DOCX + PDF) |
| 02_Manuscript | Main manuscript (DOCX + PDF), ACS-styled, tables & figures embedded |
| 03_Supporting_Information | Supporting Information (DOCX + PDF) |
| 04_Figures | Figure 1 (per-target panel + coverage–width), Figure 2 (AD calibration curve) — PDF + PNG |
| 05_Source_Data_Tables | Machine-readable CSVs for the main tables + per-target and validity data |
| 06_Graphical_TOC | Graphical Table-of-Contents image (PDF + PNG) |

All results are regenerated from public data by the released code (`code/`, MIT license),
with a one-command entry point; ADCC-CP and every baseline, the held-out panel, the validity
controls and the misspecification diagnostic each have a dedicated script (see `code/README.md`).
Datasets: MoleculeNet (DeepChem mirror) and ChEMBL (EBI REST API); no proprietary data.
