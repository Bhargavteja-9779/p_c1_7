## S-adcc-ablation. Function-class ablation

The function class is the only design choice. On the held-out panel, the indicator class reproduces Mondrian; the spline (primary) and piecewise-linear classes give the best novel-compound coverage and calibration; the normalized-score spline trades width/saturation for marginal gains (table S-adcc-panel). This confirms the class, not incidental tuning, drives the result.

## S-adcc-leak. Data-leakage audit

For every target the audit asserts chronological monotonicity (max train/calib year ≤ min test year up to boundary ties), InChIKey de-duplication, applicability-domain scores computed to the training set only, and that no labels enter featurization, AD scores or the (baseline) weight estimators. See `experiments/leakage_audit.py` and `results/leakage_audit_panel.json` in the code archive.

## S-prior. Preliminary estimated-weight benchmark and shift-magnitude diagnostic

Before developing ADCC-CP we benchmarked estimated-weight corrections (ADR-CP, MW-CP, KMM- and KDE-weighted conformal) on the same thirteen-target panel. ADR-CP, a one-dimensional density ratio along the AD coordinate, was the most effective of these (worst-stratum coverage improved over split conformal on 13/13 targets), which motivated an AD-aligned approach; ADCC-CP removes its estimation step and adds a finite-sample guarantee. In the same preliminary study a single global shift-magnitude threshold (the AUC of a classifier separating training from deployment compounds) did not predict per-target coverage failure, as summarized below; this is why the main text treats label-free shift statistics as relevance checks rather than coverage forecasts.

| Quantity | Value |
|---|---|
| Spearman ρ, shift AUC vs worst-stratum coverage (target level) | -0.016 |
| p-value of ρ | 0.957 |
| Leave-one-target-out false-safe rate | 0.538 |
| Leave-one-target-out false-alarm rate | 0.103 |
| Mean shift AUC (95% CI) | 0.875 [0.846, 0.904] |
